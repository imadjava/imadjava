# Frontend (Angular) - Skeleton

This folder contains a minimal Angular app skeleton. For production, generate a full Angular 20 project with Angular CLI and replace the files here.

How to create the full app locally:

1. Install Node and Angular CLI
2. Run: `ng new frontend --routing --style=scss`
3. Add Angular Material and configure modules
4. Implement lazy modules: home, about, admin, blog, projects, contact

This repo includes a small placeholder structure to demonstrate integration and a Dockerfile to build a production bundle.
